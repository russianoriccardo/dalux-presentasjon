# Dalux interaktiv presentasjon

En interaktiv nettside som viser hvordan Dalux **Field** og **Box** fungerer, med konkrete eksempler fra et byggeprosjekt. Selvstendig HTML/CSS/JS – ingen database, server eller byggesteg.

## 👉 Ny her? Les guiden først

- **[START-HER.pdf](START-HER.pdf)** – steg-for-steg-guiden som PDF (enklest å lese). **Begynn her.**
- [`docs/START-HER.md`](docs/START-HER.md) – samme guide i tekstformat (praktisk når du jobber med Claude).

Guiden tar deg gjennom alt: hvordan prosjektet henger sammen, hvordan du gjør endringer med Claude i nettleseren, og hvordan du legger siden ut på din egen GitHub – steg for steg, uten forkunnskaper.

## Se den lokalt
Dobbeltklikk `index.html`, så åpnes presentasjonen i nettleseren.

## Struktur
```
index.html     selve innholdet og teksten
css/           utseende (delt i moduler)
js/            oppførsel og animasjoner (delt i moduler)
docs/          dokumentasjon og overlevering
```
